# Privacy Notice

MediaFlow minimizes personal data collection. It does not require a user account. The app may process uploaded media temporarily for conversion and may log basic request metadata for diagnostics.

## Temporary data

Uploaded and generated response files are retained only as long as needed for conversion and download operations. The site owner should configure a short retention policy and periodic cleanup.

## Data handling

- Do not log passwords, tokens, or raw media payloads.
- Do not reuse uploaded user media beyond required processing.
- Keep temporary assets in a controlled workspace and clean them up promptly.
